# iOS 2.0 IPA Converter & Downloader

A GitHub Pages & Codespaces fully-ready web workspace blueprint for testing, structuring, and parsing legacy package manifests down to **iPhoneOS 2.0** target architecture specifications.

## 🚀 Features
- **GitHub Pages Enabled:** Ready-to-go static frontend interface.
- **Codespaces Integrated:** Multi-runtime development containers prepared with Python, Perl, and PHP capability.

## 🛠️ Getting Started
1. Open this repository directly inside a **GitHub Codespace**.
2. Run `python converter.py Info.plist` to evaluate metadata patching scripts.
